# My Codex Project

A lightweight, responsive starter website for creative frontend experiments. It uses Vite and vanilla JavaScript, with a soft silver-white glass-inspired visual style.

## Requirements

- Node.js 22 or newer
- npm

## Run locally

```bash
npm install
npm run dev
```

Vite prints a local URL (usually http://localhost:5173).

## Production build

```bash
npm run build
npm run preview
```

## GitHub Codespaces

1. Open this repository on GitHub.
2. Select **Code → Codespaces → Create codespace on main**.
3. Wait for the dev container to finish setting up and installing dependencies.
4. Run `npm run dev` in the terminal if it did not start automatically.
5. Open port 5173 when Codespaces offers the forwarded preview.

The dev container configuration is in `.devcontainer/devcontainer.json`.
